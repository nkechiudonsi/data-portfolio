# M&E Data Dashboard — USAID Immunization Campaign (M-RITE)

> **Impact:** 100%+ increase in data collection & processing rates · Recognised as best-performing team in Oru West, Imo State (Jan 2023)

## Project Overview

This project documents the Monitoring & Evaluation (M&E) data operations work conducted as **M&E Logistics Assistant** at USAID (M-RITE), Nov 2022 – Jun 2023. The focus was routine data quality assessment (RDQA), daily synchronisation of EMID immunization data, and workflow optimisation to support Nigeria's vaccination campaign reporting.

---

## Context

USAID's M-RITE programme conducts routine data quality reviews to ensure that health data collected at facility level is accurate, complete, and timely. Poor data quality directly affects resource allocation and programme decisions.

---

## My Role & Responsibilities

- Conducted **Routine Data Quality Assessments (RDQA)** across assigned facilities
- Managed daily synchronisation of **EMID (Electronic Medical Information Database)** records
- Reported immunization data to programme coordinators in real time
- Optimised M&E software workflows — cutting data processing lag significantly
- Collaborated with the field team recognised as **best performers in Oru West LGA, Jan 2023**
